# 背单词网页应用设计（手机端）

## 目标与范围
- 面向准备英语六级的用户，提供随时可用的背单词工具。
- 首版聚焦“词卡背诵”，减少复杂功能，保证稳定与易用。
- 离线可用，不依赖账号登录；数据全部存本地。

## 用户体验与页面
- 启动页：选择学习计划（每日词量），进入学习。
- 词卡页：核心界面，一次只显示一个单词；点击显示释义，再点显示例句与词性；支持左右切换与按钮切换。
- 复习页：显示今日完成情况与待复习入口。
- 词表页：查看进度、按首字母/关键词搜索。

## 数据与词表
- 内置六级高频词表 + 基础词表，总量约 5500 词。
- 词表以静态 JSON 随应用打包，首次进入写入本地存储。
- 每个词条包含：单词、音标、释义、例句、词性、难度标记。

## 数据流与状态
- 首次进入：初始化词表与默认计划。
- 每日生成“今日新词 + 复习词”队列。
- 点击“显示释义/例句”视为一次学习记录；完成后标记为“已学”。
- 复习安排采用简单间隔（如 1 天/3 天/7 天）；后续可替换更细的算法。
- 进度与计划保存在本地，离线可用。

## 架构与组件
- 纯前端单页应用，移动端优先布局。
- 核心组件：启动页、词卡、复习列表、词表/搜索、设置入口。
- 本地存储层封装读取/写入与数据迁移。

## 错误处理与恢复
- 本地数据损坏或首次加载失败时提示重试，并提供“重置学习数据”入口。
- 浏览器不支持存储时提示兼容性问题并给出解决建议。

## 测试要点
- 词表初始化与本地写入。
- 学习计划生成与今日队列生成。
- 复习安排递推逻辑。
- 进度持久化与恢复。
- 离线访问与断网场景。
